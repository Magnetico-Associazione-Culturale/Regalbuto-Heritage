# Regalbuto-Heritage
App turistica del Comune di Regalbuto, sviluppata come sito statico (HTML/JS) e visualizzata via WebView su Android/iOS. Include guida ai monumenti, mappa interattiva, **navigazione GPS con MapLibre GL JS**, quiz e Virtual Tour. Hosting su Azure, codice open-source per facile manutenzione e aggiornamento.

## 🆕 Nuove Funzionalità

### Navigazione GPS
- **Itinerario turistico guidato** con MapLibre GL JS
- **Tracciamento GPS in tempo reale** della posizione dell'utente
- **Indicazioni turn-by-turn** per raggiungere ogni monumento
- **Progresso automatico** del percorso con checkpoint
- **Calcolo distanze** e tempo stimato
- **Interfaccia ottimizzata** per dispositivi mobili

### Caratteristiche Tecniche
- Utilizza **MapLibre GL JS** per mappe vettoriali performanti
- Dati del percorso in formato **GeoJSON**
- **Geolocation API** per il tracciamento preciso
- **OpenStreetMap** come base cartografica
- **Completamente offline** una volta caricati i dati
